## 1. 定位与目标

个人自用 Windows 桌面 Markdown **阅读器**：阅读为主 + 轻量编辑 + 导出 PDF。

**立足点（差异化）**：竞品没有一个同时占住「浏览器级排版质量 + 中文优先排版」——
- Ferrite（Rust + egui）：自绘文本无 CSS 排版能力，中文两端对齐/混排间距/标点挤压全做不了
- MarkView（Tauri + Next.js/React/Tailwind）：有 WebView2 但 react-markdown 慢、无中文排版投入
- MD Reader（Tauri，4.2MB msi）：方向对但中文排版与导出未做到位
- **隐性第四竞品（beta 席洞察）：浏览器直接开 .md / VS Code 预览**——墨读必须比它在中文排版上强一档、在"打开即读 + PDF 交付"上轻一档，因此中文排版验收以**浏览器默认渲染并排截图**为基线，不做内部"通过"

**用户场景**：财务/数据从业者，双机（公司内网机 + 家机外网），读技术文档、AI 输出、自产分析报告 .md（含大量 `$` 货币金额——数学分隔符策略因此受限，见 D2）；随手改错字；需要时导出 PDF 交付。

### 2.2 非功能需求

- 包体积 **≤8MB msi 硬门禁**：M0 记骨架基线，M1 起真实依赖集每批过门禁；超则按预排顺序削减（hljs lib/common → KaTeX 字体子集 → emoji 短码 → Mermaid 最后）。**懒加载只省启动耗时，不省 msi 体积**（三席一致纠正）
- 性能：冷启动与内容加载**分开计量**；1MB/~5000 行文档内容渲染 <1s、滚动不卡；5000 行文档专测（滚动 CSS 杀手 + justify 断行）；不做虚拟滚动
- **安全（C0-1，alpha 席）**：墨读是持 Tauri IPC 的活 WebView，`innerHTML + html:true` 下 `<img onerror>` 可执行并 invoke fs 命令；AI 输出可被提示注入污染。三项全做：① CSP 非模板默认；② capabilities 按"渲染层已攻陷"设防，fs 路径 scope 收紧到用户主动打开的文件；③ 渲染管线挂 DOMPurify（~22KB）。`html:true` **默认关**

### 2.3 明确不做（YAGNI）

Word 导出（OMML 全链）✂️；jsPDF/html2canvas 光栅化 ✂️；**F11 导出 HTML 单文件**（三席全砍：KaTeX base64 内联机器连带删除；真要交付 HTML 时"导出文件夹"另议）✂️；多光标/补全/Vim ✂️；插件系统 ✂️；云同步 ✂️；**骨架屏**（用户拍板砍，用 loading 指示符）✂️；沉浸滚动工具条淡出（M5 观望）✂️；`==text==` 等自制语法扩展（读写体验分裂）✂️；protectMath/restoreMath 占位符 hack ✂️；手写 footnotes/TOC ✂️；文件夹工作区与跨文件搜索（二期另立计划）✂️；CM6 Live Preview（三期可选）✂️。

### 3.2 交互

- `Ctrl+E` 阅读↔编辑整态切换（编辑态同一位置换 CM6，行宽一致；切换大文档时有 loading 态）
- `Ctrl+F` 查找条；`Ctrl+H` 替换（编辑态）；`Ctrl+P` 导出；`Ctrl+S` 保存
- 内容加载用 loading 指示符（骨架屏已砍）；focus-visible 可见焦点态保留

### 3.3 主题与排版 demo 协议（强制）

- **色值只从 Radix Colors 阶数取（UI 单体系）；结构刻度（间距/字号/圆角/阴影）用 Open Props 最小实用集**（用户拍板 2026-09-21，约十几个值，不建完整 token 体系）
- 亮暗双套成对设计、同步验收；正文对比度 ≥4.5:1；语义色红错绿过黄警蓝信
- **M1 排版 demo 评审轮**：真场景页（标题/正文/表格/代码/公式/Mermaid + 含 `$1,000` 金额 + 含引号语料）出 **A/B 两版（不带/带 pangu）+ 浏览器默认渲染并排对照**，用户否决定稿，先于一切 GUI 代码

## 4. 架构决策（D1–D7，v1.1 评审后）

| 决策 | 裁决 | 关键修改（v1.1） |
|---|---|---|
| D1 编辑器底座 | **双引擎切换**：阅读态=markdown-it 静态 HTML；编辑态=CM6 | ① 块级定位验收降级（token.map 是块级，inline 无 map）② EditorView 常驻只改显隐保撤销链 ③ 无 map 块落最近上方块 ④ 异步高度漂移三件套：百分比兜底 + Mermaid/KaTeX 内容哈希缓存 + 3-5 文件回归语料 ⑤ `breaks:true` 是显式决策进台账 ⑥ golden-HTML 覆盖 data-line |
| D2 PDF 导出 | **单路径 = PDF 导出**（同引擎、同渲染管线、静默无对话框）。**2026-09-23 评审批准将载体由 `ICoreWebView2::PrintToPdf` 变更为 CDP `Page.printToPDF`**（`headerTemplate` 置空 = 无页眉；`footerTemplate` 只放 `pageNumber` = 仅页码）。理由与证据见 `docs/review/2026-09-23-红线勘误与打印载体变更评审.md` | ① 数学分隔符定策（C0-3）：仅 `$$...$$` + `\(...\)`/`\[...\]`，**禁裸 `$...$`**（金额 `$1,000` 纯文本安全）；用 markdown-it 数学插件 ② `@page{size:A4; margin:18mm}`，body 不放页边距（毒资产判死）③ 表格行级分页 `tr{break-inside:avoid}` + `thead{display:table-header-group}`，**剔整表 avoid** ④ `.katex-mathml{display:none}` 防 PDF 鬼影 ⑤ 打印前 await 渲染完所有懒加载块 ⑥ 页眉页脚真样张 spike 前置 M4（FooterUri 默认 URL 丑，"— 3 —"中式页码做不到，能力 M5 实测）⑦ 编辑态导出先切阅读态 |
| D3 中文排版 | justify + `text-spacing-trim`(123+✓) + 行高 1.8 + 限宽 46em + `overflow-wrap:anywhere` | **pangu 砍出 M1**（用户拍板：demo A/B 后定；若定做则白名单元素 + `span.cjk-gap` 非破坏 + copy/find 规范化）；typographer 与 pangu 职责去重（含引号语料测清）；`text-autospace` 的 CSS.supports 预留分支**不写**（Chrome ≤153 全红，留死代码无益） |
| D4 性能 | 无虚拟滚动；懒加载 + 分块渲染 | **禁用 highlightAuto**（无标注纯转义或限 5 候选，性能第一杀手）；Mermaid 每帧上限 N 图队列；非活动标签只留源文本；编辑→阅读切换 loading + 哈希缓存；冷启动/内容加载分开计量 |
| D5 Print Studio 资产 | 大幅收回 | **只搬 4 条**：`print-color-adjust:exact`、`box-decoration-break:clone`、`page-break-inside:avoid`（块级）、`thead{display:table-header-group}` + markdown-it 配置与 fence 规则（剔除其中 highlightAuto 分支）+ `refreshMermaidTheme` 思路。**不搬**：`@page{margin:0}+body padding`（毒资产）、protectMath/restoreMath、`html:true`、`==text==` 扩展、KaTeX base64 预载缓存、L2426"打印机剥 CSS 变量"错误诊断。**print.css 定为 cjk.css 唯一覆盖层，禁止第三份**（防多份漂移重演）。`参考/` 目录入库 |
| D6 安全模型（新增） | 三项全做 | CSP 非模板默认 + capabilities 按"渲染层已攻陷"设防（fs scope 收紧）+ DOMPurify；`html:false` |
| D7 编码语义（新增） | GB18030 回退读入的文件保存**保持原编码** | 不静默转 UTF-8（防坑用户其他工具）；状态栏显示编码；DSE 场景 M1 读写**双**测 |

## 6. 质量门禁

- `tsc --strict`（禁 any）+ eslint + vitest，一条命令 `pnpm check` 全绿才许提交
- **golden-HTML 快照对拍**：固定语料含 ①`$1,000 上涨 20%` 金额串 ②复制/查找保真用例 ③data-line 属性本身 ④引号语料（typographer）
- **M1 三场景验收**：从渲染页复制混排文本粘贴无垃圾空格 / Ctrl+F 查原文命中 / 打开即 Ctrl+P 检查 Mermaid 全渲染
- **中文排版验收**：与浏览器默认渲染并排截图对照
- 排版走截图验收轮：E2E 截图→发现问题→修复→同名截图复核
- Rust 侧 `cargo test`
- TS 铁律（用户拍板 2026-09-21）：**函数 ≤50 行保留；文件上限 400 行**（UI 组件天然 300-400 行，逻辑文件自觉 250）；禁宽 catch/空 catch；全类型注解
- 错误信息中文、面向使用者

## 8. 风险与对策（评审后合并 Top5）

1. **R1 PDF 交付在 Tauri 未验证** → M0 双 spike + 止损线（C0-2）
2. **R2 字距系统破坏财务场景**（$ 货币/复制/查找）→ D2 分隔符定策 + M1 三场景验收
3. **R3 8MB vs 依赖集冲突（实算 8-11MB）** → M0 基线 + 硬门禁 + 削减顺序
4. **R4 安全模型盲区** → D6 三项全做（M0/M1 定了难改，半天成本）
5. **R5 双引擎慢性体验崩坏** → EditorView 常驻 + 哈希缓存 + 百分比兜底 + 回归语料
6. 环境残存项：rustup 未装（M0-1）；WiX 首次下载（家机先跑通带缓存）；家机 MSVC 待核；git 身份未配（提交作者显示为 `unknown <user-email>`，双机同步前需用户定）
7. DSE 透明加密：.md 理论不在加密清单，M1 读写双测验证；异常则记录走系统兜底
