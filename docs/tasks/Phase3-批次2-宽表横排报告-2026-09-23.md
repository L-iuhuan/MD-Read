# Phase 3 · 批次 2 · 宽表自动横向打印报告（2026-09-23）

- 用户裁决：**宽表自动横向打印**（不是"只提醒"）。
- 实现边界（严格按 Lead 指令 + 侦察所能覆盖的一段）：**竖版可印宽 < 块内容宽 ≤ 横版可印宽**（≈`658 < w ≤ 987`）
  的 `.table-wrap` → 打印时**命名页横排**；**更宽的块不横排、不缩放、不拆列**，由已有 `overflowWarning` 提醒兜底。
- 证据：`.verify/phase3b/{probe-pagewide.mjs（侦察）, probe-wide1.mjs, probe-wide-export.mjs}`
  数据 `out-pagewide-*.json`、`out-wide-*.json`；产物 `export/{pagewide-{named,plain}.pdf, wide-{left,right}.pdf, widep-1..4.png}`

## 1. 能力侦察（实测，先做）

页面级临时注入（**未改产品代码**）：`@page wide { size: A4 landscape }` + `.table-wrap { page: wide }`。

| 侦察项 | 实测结果 |
|---|---|
| 命名页是否受支持（WebView2 153.0.4234.48 + CDP `Page.printToPDF` + `preferCSSPageSize:true`） | **受支持** ✓ 逐页纸型：p1 594.96×841.92（竖）/ **p2 841.92×594.96（横）** / p3 竖 |
| 对照组（同语料、只强制分页、**不加**命名页） | **三页全竖** ⇒ 横版页可归因于命名页（**决定性对照**）✓ |
| 同一 PDF 内混排竖/横 | **生效** ✓ |
| 横版可印宽 | ≈ 261mm ≈ **987px**（由实测纸型 841.92×594.96pt − 2×18mm 换算；"mm⇒px"按 96dpi 属**推断**） |
| 12 列超宽表（内在宽 1870px）能否被横排救活 | **不能** ❌ 横排后文本层仍无 `列12` ⇒ 横排只覆盖 `(658, 987]` |

## 2. 实现（只加类，屏显零影响）

- `src/render/print-ready.ts`：新增 `PORTRAIT_PRINTABLE_PX = 658` / `LANDSCAPE_PRINTABLE_PX = 987`
  （**注释写清来历**：174mm/261mm 由实测纸型 − 2×18mm 得出，mm⇒px 是推断）、
  `blockContentWidth()`（取 `max(表自然宽, 容器 scrollWidth)` —— 屏显时容器可能比表宽，不能只看容器）、
  `markLandscapeBlocks(root)`（`658 < w ≤ 987` → `wide-page`；幂等，每次重算并清旧标记）、
  `tooWideBlocks(root)`（`w > 987` → 只提醒）、`overflowWarning(labels)`（文案改为
  「本文档有 N 处表格比 A4 横版可印宽还宽（宽表格），PDF 中可能被截断」）。
  `pre` **不进清单**（print.css 已让长代码行换行）。
- `src/typography/print.css`（**唯一打印层**）：新增 `@page wide { size: A4 landscape; margin: 18mm }` +
  `.mdc .wide-page { page: wide }`，注释写明实测依据与边界；`tr{break-inside:avoid}`、
  `thead{display:table-header-group}`、`@page{size:A4;margin:18mm}`、body 无页边距**全部未动**。
- `src/main.ts`：导出前 `markLandscapeBlocks(doc)` + `overflowWarning(tooWideBlocks(doc))` 提醒。
- `tests/print-overflow.spec.ts` 重写：阈值常量、`blockContentWidth`、两侧边界（658 不横排 / 659 横排 /
  987 横排 / 988 不横排）、幂等与清旧标记、超宽只提醒不横排、文案不含技术黑话、
  **print.css 契约锚**（`@page wide` + `.wide-page{page:wide}` + 行级分页 + 表头重复 + 默认 `@page` A4/18mm）。

## 5. 遗留（如实）

- **超过横版可印宽（>987px）的宽表仍会被裁**：这是**已知边界**，本轮**按指令不缩放/不拆列**，
  由 `overflowWarning` 提醒兜底；彻底方案（缩排 / 拆页 / 拆列）**等用户裁决**。
- 预/后对比（12 列超宽表）：改前 = 丢列 + 残留滚动条；改后 = **仍丢列，但不再有滚动条，且有中文提醒**
  （横排只对 `(658, 987]` 生效，1870px 超出该区间）。
- 中等宽表的**行级分页**已验证；**跨 3 页以上的超长中等宽表**本轮未单独造用例（现语料 45 行 = 2 页）。
