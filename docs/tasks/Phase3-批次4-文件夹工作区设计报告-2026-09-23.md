## 1. 面板形态 & 与既有面板的关系
- **树**（非扁平列表），与侧栏 ③ 大纲**共用一个侧栏**，标题栏「**大纲 / 文件夹**」二选一切换
  （不新开第二列 —— 正文限宽 ~46em 是规格红线）
- **逐级懒加载**：点开某级才列该级（**不递归全盘扫描**）
- 点文件 = **按既有去重逻辑开标签**（同路径已开则激活）；**不做多选**
- **最近文件不改**（分工：树里找 vs 最近用过）

## 2. 键盘 / 空状态 / 大目录性能
- 键盘：`↑↓` 移动 · `←→` 折叠/展开 · `Enter` 打开 · `Esc` 回正文 · 侧栏快捷键进入焦点
- 空状态：「还没有工作区 —— 选一个文件夹开始」+ 按钮（**Rust 侧原生选目录对话框**）
- 性能：只读已展开层级 · **不做文件监视** · **不做虚拟滚动**（先设渲染上限）
- ⚠ **上限值必须实测**：量「首屏渲染耗时 vs 条目数」（200 / 500 / 1000 / 2000）⇒ **按实测选定并把数字写进报告**（不养魔法数）
  超过上限时尾部显示「还有 N 项」并可继续展开

## 3. 信任边界（**二选一：A**）
| 方案 | 结论 |
|---|---|
| **A. 复用受信清单**（新增「**目录类型条目**」；登记通道与文件相同：Rust 侧对话框 / OS 拖放 / argv / 持久化清单）| ✅ **采纳**（Lead 已批）|
| B. 新增「只读目录授权」独立通道 | ❌ 否决：引入**第二套信任模型**（两处判定、两套失效语义），扩大面更大、收益为零 |
理由：R-01 本就是"**读写在受信集合内才放行**"⇒ 扩的是**条目类型**，不是**信任模型**
- 目录条目授权范围：**列目录 + 其内文件读写**（canonical 后判定；`..`/符号链接/UNC 既有规则照旧）
- **渲染进程仍不得注册信任**（R-01 原样保留）

### 3.1 ⚠ 授权范围**必须在 UI 里说出来**（防"静默扩大"）
选目录的对话框/提示必须写明：**「其中的文件可被打开并编辑」** —— 否则"选个文件夹浏览一下"= **静默授予整个子树的可写权** ✗
（若用户要**只读工作区**，请他明说，我们再收窄）

### 3.2 ⚠ 撤销路径（信任只增不减 = 隐患）
侧栏工作区节点的右键/上下文菜单提供 **「移除工作区」**（= 从受信目录条目中删除该目录）⇒ 立即生效（重判当前打开的文件是否仍受信）。
**验收**：移除后该目录下新路径被拒；已打开的标签保留（该文件可能仍在受信文件集里），但**再次打开被拒** ✓

### 3.3 ⚠ 前缀匹配必须按「**路径分量**」判，不能按字符串前缀 ✗✗
受信目录 `C:\a\b` **不得**匹配 `C:\a\bc\...` ⇒ canonical 后**按分量比较**（`\` 分隔后逐段比）✓
**验收必须含这条** ✓

## 4. D-11 × R-01 的交界点
- **是否扩大信任面**：**是，明确扩大** —— 从"用户打开过的**那些文件**"扩到"用户选中**目录下的一切**"
- **扩在哪一层**：**Rust 侧** —— 判据从"路径 ⊆ 受信文件集"扩为"路径 ⊆ 受信文件集 ∪ 受信目录下（canonical **分量前缀**匹配）"；
  **前端只请求与呈现、不判权限**（前端永远不判"能不能读"，只显示 Rust 的拒绝）
- **新增验收**：见 §6

## 5. 3 处设计缺口（Lead 补，已折入）
1. **持久化**：新键 `modu-workspace`（沿用既有 `modu-*` 约定；**键名是兼容面** ⇒ 一旦发布不得随意改）
   内容 = 当前工作区**根目录路径**（或 `null`）；启动时**最多恢复一个**工作区（多余的在列表中供切换，不自动展开）
2. **降级要优雅**：目录**不可读/权限拒绝/项数超限/已被删除** ⇒ 在该节点位置显示**原因文案**（中文、面向使用者），**不崩**
3. **「大纲/文件夹」切换不得扰动大纲既有状态**：滚动跟随、活动项、折叠状态**切回来必须原样**（验收项）

## 6. 验收清单（9 条，实现后逐条真机验）
1. 目录外路径**仍被拒** ✓
2. `..` / 符号链接**逃出**受信目录 ⇒ **必拒** ✓
3. 渲染层调注册命令 ⇒ **不存在该命令** ✓
4. 授权只在**用户显式动作**（对话框/拖放/argv）后产生 ✓
5. **分量边界**：受信 `C:\a\b` **不匹配** `C:\a\bc\...` ✓
6. **撤销路径**可用（移除工作区 ⇒ 该目录下新路径被拒）✓
7. **不可读目录**显示原因、不崩 ✓
8. **切换回来大纲状态不变**（滚动跟随/活动项/折叠）✓
9. **上限值有实测依据**（200/500/1000/2000 的首屏渲染耗时表）✓
