## 2. 六条护栏（逐条落位）
1. **只动 `dirs`** ✓ —— **不动 `files`** ✓（与设计"已打开标签保留（该文件可能仍在受信文件集里）"一致）
2. **必须先已在 `dirs` 内** ✓ ⇒ 否则 `DenyReason::Untrusted` **拒绝**（不是静默 no-op）
3. **删后立即 `persist()`** ✓（该清单**只在启动时 load 一次** ⇒ 只改内存 = **重启复活** ✗）
4. **立即生效** ✓（读路径同一份判据；**不关已打开标签** ✗）
5. **UI 文案要真** ✓：「该目录下的新文件将被拒绝」（**不写**"仅从侧栏隐藏"）
6. **审计日志** ✓：`println!("[trust] 移除受信目录 …")`
   ⚠️ **覆盖声明：实现，未被任何锚断言**（单测抓 stdout 不划算 ⇒ 如实声明，不为覆盖率硬造夹具 ✗）

### 2.1 ⭐ 堵掉"目录已消失"残留（否则该授权**永远删不掉** ✗）
`canonicalize` 失败时 ⇒ 用 raw 的规范化键（小写；带/不带 `\\?\` 两种形态）在 `dirs` 里做
【**全等匹配**】；⚠ **绝不允许前缀匹配** ✗（那会一次删掉一串授权）。

### 2.2 方向性：**只减不增**（渲染层唯一被允许的受信集合写操作）
它**不能授予**任何访问 ✗；最坏情形只是"用户自己的授权被静默删掉" = **便利性损失，不是越权** ✓
（R-01 本意是防"渲染层**自我授权**"✗；`trust_directory` / `trust_existing` 仍**不是** `#[tauri::command]` ✓）

## 5. ⭐ 三条通用教训（本轮新增，已入 `AGENTS.md` `2c7cdca`）
### 5.1 种入受信目录必须是【canonical 小写 ＋ `\\?\` 前缀】形态（**复现两次** ✗）
写成 `D:\Files\…` 原始形态 ⇒ `dirs` 里存的是小写 `\\?\` 键 ⇒ 匹配不上 ⇒ **应用一律拒绝**
⇒ 现象"看起来像产品缺陷" ✗（第 2、3 轮真机验收都因此连"移除前"都被拒）。
⇒ 自证法：`realpathSync.native(p).toLowerCase()` 与自己的键**逐字比对**（别只看"我写进去了"）。

### 5.2 ⭐ 真机验收必须整体放进【同一条长命命令】
**成对判据**（样本量如实：**A/B 各 1 次 ＋ 历史 2 次同形**）：
```
B（同一条长命命令）：启动 ⇒ 就绪 ⇒ 正对照/四条 ⇒ 截图 ⇒ 优雅关闭 ⇒ **21s 全程存活** ✓ ＋ 正常 `[child-exit] code=0` ✓
A（后台作业起）    ：**13s 内静默消失** ✗ ＋ **无 `[child-exit]`** ✗ ＋ 事件日志**无崩溃条目** ✗（= "被请走"不是"自己崩"）
⇒ 定案（**推断**，判据为 A/B 对照）：**harness 作业生命周期产物** —— 发起轮结束时 harness 的 **Windows Job
   回收进程树** ⇒ 探针起的应用被静默带走 ✗ ⇒ **不是产品缺陷** ✓
⇒ 推论：**任何"应用自己退出了"的怀疑，先排除这一条**（本项目已因此白查两轮 ✗）
```
**用户侧**：用户明确回答「**我没有关窗口**」⇒ "人关的"（a）**排除** ✓ ⇒ 按技术性（b）处置 ✓。

## 6. 其余素材（同一批的其他教训）
- ⭐ **断言要钉完整串，不能只钉前缀** ✗：只断 `toContain("无法列出目录")` ⇒ 面板硬编码一句相似文案也会过
- ⭐ **把区分的两侧都钉住**：只钉"列目录失败不清指针"不够 ⇒ 还要钉"**显式移除无论成败都清**"（三态合起来语义改不动）
- ⭐ **显式路径纪律顺手抓出我自己的路径错字**：`fs_trust_tests.rs` 在 `modu/src-tauri/src/` 下，我写成 `modu/tests/…`
  ⇒ `git add` 报 `pathspec … did not match any files` ⇒ **门禁拒绝提交**（若用裸 `git add -A`，缺锚的提交会静默放出去 ✗）
- ⭐ **`msedgewebview2` 6 个杀不掉 = 结案：Windows 搜索常驻进程**（`StartTime` 固定 ＋ 父链 → `SearchHost.exe`）
  ⇒ 判据用**父链 / StartTime**，**别用裸计数** ✗
- ⭐ **包装脚本的"还原"会把探针的启动前种入写回去**（它自证：`[child-exit] … 恢复(W=true sha=…)`）
  ⇒ **正确顺序：先让包装脚本/应用完全退出，再写回原文** ＋ **10s 稳定复读** ✓
- ⭐ **"验收脚本不许碰真实数据"**：临时 store ＋ 跑锚**前后**读真实清单 sha 断言一致（基线 `8B327C9A1046395A`）
- ⚠ **别在 harness 跟踪的后台作业里杀该作业树的进程** ✗（实测会撕掉跟踪范围 ⇒ `Windows Job runner exited 4294967295`）
