## 2. 为什么 `dataDirectory` 没隔离（**实测 + 推断分段**）

- **实测 ①**：四个 overlay（`.verify/dev/*.conf.json`）都在 `app.windows[0]` 写了 `"dataDirectory": ".verify-cdp"`（分别 `.verify-cdp / .verify-cdp-narrow / .verify-cdp-big / .verify-p16-cdp`）。
- **实测 ②（语义）**：Tauri 2 的 `tauri-utils 2.9.3` `src/config.rs` 该字段文档原文——
  「Set a custom path for the webview's data directory (localStorage, cache, etc.) **relative to `appDataDir()/${label}`**」，
  且**平台支持**里明确列 **Windows**（"WebViews with different values for settings like `additionalBrowserArgs` … **must have different data directories**"）。
  ⇒ 按文档，落点应是 `%APPDATA%\com.modu.reader\main\.verify-cdp\…`。
- **实测 ③（决定性）**：`%APPDATA%\com.modu.reader` 下**没有**任何 `.verify-*` 目录、**没有**独立 `leveldb`；
  而**真实 profile 的 `000010.log` 末写时间 = 2026-09-25 15:28:30**（正是本批测试轮的时间）
  ⇒ **独立目录从未被创建，而真实 profile 持续被写** ⇒ **`dataDirectory` 在本 setup（Tauri CLI 2.11.5 / tauri-utils 2.9.3 / Windows）下对 WebView2 的 user-data folder 不生效** ✓（**你的前提成立**）。
- **推断（未验证，标推断）**：Windows 上 Tauri 把 WebView2 的 user-data folder 固定为 `%LOCALAPPDATA%\<identifier>\EBWebView`，
  配置键 `dataDirectory` 未接进去；WebView2 官方提供的覆盖路径是 **`WEBVIEW2_USER_DATA_FOLDER` 环境变量** ——
  这也是本项目已知"`WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS` 会被 Tauri 覆盖"的**同族**问题，需**以实测为准**。
