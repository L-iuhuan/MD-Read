## 二、"换机能不能用"的三个硬条件（逐条实测 ✓）

1. ⭐ **exe 不依赖未随包发布的外部 DLL** ✓
   `release exe` / `msi` / `nsis` **三者都不含 `WebView2Loader.dll` 字符串** ✓（字节级扫描 ✓）
   —— 修掉的是**产品缺陷 A**：旧的 `[patch.crates-io]` 动态加载器补丁让 exe 在加载期依赖该 DLL，
   而它既不入库、也不随包发布 ⇒ 旧包在**任何**没有该 DLL 的机器上都可能起不来 ✗
2. **安装模式** ✓ `nsis.installMode = currentUser`（免管理员 ✓）；MSI 是 per-machine ⚠
3. **运行前置**：**WebView2 Evergreen 运行时**（Win11 自带 ✓；老 Win10 / LTSC / 精简镜像可能没有 ⚠）
   ＋ 装包期**需联网一次**（`downloadBootstrapper` ✓ 已显式写出 ✓）
   ＋ 离线机：把 `%LOCALAPPDATA%\tauri\MicrosoftEdgeWebview2Setup.exe` 一并交付 ✓
