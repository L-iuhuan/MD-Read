## 二、"换机能不能用"的三个硬条件（逐条实测 ✓）

1. ⭐ **exe 不依赖未随包发布的外部 DLL** ✓
   `release exe` / `msi` / `nsis` **三者都不含 `WebView2Loader.dll` 字符串** ✓（字节级扫描 ✓）
   —— 修掉的是**产品缺陷 A**：旧的 `[patch.crates-io]` 动态加载器补丁让 exe 在加载期依赖该 DLL，
   而它既不入库、也不随包发布 ⇒ 旧包在**任何**没有该 DLL 的机器上都可能起不来 ✗
2. **安装模式** ✓ `nsis.installMode = currentUser`（免管理员 ✓）；MSI 是 per-machine ⚠
3. **运行前置**：**WebView2 Evergreen 运行时**（Win11 自带 ✓；老 Win10 / LTSC / 精简镜像可能没有 ⚠）
   ＋ 装包期**需联网一次**（`downloadBootstrapper` ✓ 已显式写出 ✓）
   ＋ 离线机：把 `%LOCALAPPDATA%\tauri\MicrosoftEdgeWebview2Setup.exe` 一并交付 ✓

## 三、换机验收清单（在**另一台**机器上做；判"起没起来"一律用三层判据）

**三层判据**（AGENTS 定稿）：① 本进程 `--type=renderer` 且 `--user-data-dir` 含 `com.modu.reader` 的
子进程 ≥1；② profile 有写入（`EBWebView` 下文件 mtime 前进）；③ 窗口标题 == 配置标题 **且** 同一 PID 在
T+3s 与 T+15s 都存活。**连跑 3 次全绿**才算过。

| # | 做什么 | 期望 | 失败说明什么 |
|---|---|---|---|
| 1 | 干净 Win11、**断网**，双击 NSIS 安装包 | 免管理员装完；`%LOCALAPPDATA%\MoDu\modu.exe` 存在 | 失败 ⇒ 安装器确实要联网下 WebView2 引导器，或目标机缺运行时 |
| 2 | 用**非管理员**账号试装 MSI | 明确失败（`Error 1730`） | 非管理员竟能装 ⇒ 需重判 MSI 语义 |
| 3 | 装完**立即**启动，静置 20 秒不操作 | 窗口在、页面渲染、**不弹**任何"墨读启动失败"框、进程不被自杀 | 弹框后退出 ⇒ 看门狗判据在目标机成立失败（**不是**没装好） |
| 4 | 起应用后 `CloseMainWindow()`，**5 秒内**再启动 | 第二次正常出窗口 | 第二次静默无反应 ⇒ 单实例锁未释放（**别用强杀** ✗，localStorage 不落盘） |
| 5 | 用**含空格用户名**（如 `<含空格的用户目录>`）重复 1–4 | 全通过 | 失败 ⇒ 命令行/路径拼接缺引号 |
| 6 | 建 **GB18030 + CRLF** 的中文 .md，双击打开、改一字保存 | 状态栏显示编码；保存后**仍是 GB18030/CRLF** | 变 UTF-8 ⇒ 编码契约破了（红线） |
| 7 | 打开引用 `./pic.png` 的相对图片文档 | 图片显示 | 图 404 ⇒ asset scope / CSP 在目标机被拦 |
| 8 | 打开**另一块盘**上、以及 **UNC** `<UNC 路径>` | 都能打开 | UNC 失败 ⇒ 路径规范化/权限 |
| 9 | 设置里点"设为 .md 默认应用" → 系统默认应用页选墨读 → 关设置 → 双击 .md | 用墨读打开 | 仍开别的 ⇒ `UserChoice` 未建立（**Windows 不允许应用代设** ⇒ 属预期，必须在交付说明里写清） |
| 10 | 导出含**超宽表**的 PDF | 生成 PDF；表格三层（竖/横/压列）不丢列；页码为「— n —」 | 失败/超时 ⇒ 打印链或字体等待上限 |
| 11 | 目标机缺中文字体的语言镜像 | 界面中文可读（回退到某中文字体） | 全是豆腐块 ⇒ 需把中文字体列为运行前置 |
| 12 | 在目标机自己做 `pnpm install && pnpm tauri build` | 产出两份安装包 | 失败 ⇒ 看 npm/crates 源、pnpm 版本、`%LOCALAPPDATA%\tauri`（WiX/NSIS）缓存 |
| 13 | 收尾留档：第 1–4 条的进程判据输出、`reg query HKLM\SOFTWARE\Classes\.md`、受信清单内容 | 可追溯 | —（这条是给**下次**换机的基线，避免重演"证据链被自己毁掉" ✗） |
