# 用例⑥ 编辑态操练区（按 Ctrl+E 切到编辑）

逐条做，对照期望：

| 操作 | 期望 |
|---|---|
| 光标停在某个任务行上，看另外一行 | 有勾选框 |
| 光标放在 `> 引用行` 上按 Ctrl+Enter | 变成 `> - [ ] 引用行` |
| 光标放在 `1. 有序项` 上按 Ctrl+Enter | 变成 `1. [ ] 有序项` |
| 光标放在代码块里那行按 Ctrl+Enter | 什么都不该发生 |
| 光标放在缩进的 `# 缩进标题` 上按 Ctrl+2 | 变成两枚井号、缩进保留 |
| 输入 `[` → 选补全「链接」→ 直接打一个字 | 得到 `[新](地址)`，链接完整 |
| 输入 `$$x$$ 与 **粗体**`，光标移开 | 粗体在编辑态也显示为粗体 |

---

- [ ] 未完成任务
- [x] 已完成任务
