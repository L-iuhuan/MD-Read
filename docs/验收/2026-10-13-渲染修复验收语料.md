✅ 应看到**居中的公式排版**（E = mc² 的数学字体）。

✅ 两块都应是居中公式排版；第二块应排成对齐（&= 对齐）形式。

\end{aligned}
$$

✅ 行内应出现小号数学排版；方括号那处应是独立居中的公式块。
❌ 露出反斜杠定界符、或退化成普通括号。

行内：\(x_i^2 + y_i\) 与 \(a^{n}_{m}\)。

方括号显示式：\[\int_0^1 x \, dx = \frac{1}{2}\]

### A4 纯中文公式（有意「降级」，不是 bug）
✅ 公式文字以**衬线体居中**显示，没有美元定界符。
（KaTeX 排中文会很难看，所以含中文的公式被有意降级成朴素排版。）

$$

$$

### A5 金额红线（绝不能变成公式）
✅ `$1,000 与 $2,000`、`¥12,345.67`、`裸 $x$` 全部**原样纯文本**。
❌ 金额被吃掉或进了公式排版。

预算 $1,000 与 $2,000 合计，应收 ¥12,345.67；裸 $x$ 与 $ y $ 都不是公式。

## E. 「需要空行」的真相（这些是规范，不是 bug —— 你可以自己确认）

看点不是好看，而是「和主流 Markdown 一致」。下表这些都是**规范行为**：

| 你写的样子 | 期望 | 判定 |
|---|---|---|
| 段落下一行直接写表格 | 成表格 | 正常，**不需要**空行 |
| 段落下一行直接写 `- 项` | 成列表 | 正常 |
| 段落下一行直接写 `1. 项` | 成有序列表 | 正常 |
| 段落下一行直接写 `2. 项` | **不成列表**（并进段落） | 规范：只有 `1.` 能打断段落 |
| 段落下一行直接写 `> 引用` | 成引用 | 正常 |
| 段落下一行直接写 `# 标题` | 成标题 | 正常 |
| 段落下一行直接写 4 个空格 + 文字 | **并进段落**（不是代码块） | 规范 |
| 段落下一行写 `---` | **变成二级标题** | 规范（想要横线请用 `***` 或 `___`） |
| `- 项` 的下一行直接写字（不缩进） | 文字**并进那个列表项** | 规范（懒延续）—— 加空行即分离 |
| `> 引用` 的下一行直接写字 | 文字并进引用 | 规范 —— 加空行即分离 |
