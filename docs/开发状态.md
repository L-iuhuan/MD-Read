# 墨读（MoDu）开发状态与接续指南

> 本文件是跨机器接续开发的入口文档。更新于 2026-09-22。
> 远程：https://github.com/L-iuhuan/MD-Read（main 分支）｜另一台机器从本文件开始读。

## 一句话

个人 Windows Markdown 阅读器「墨读」：**Tauri 2 + vanilla TypeScript + 手写 CSS**，阅读为主 + 轻量编辑 + 导出 PDF，msi 约 4.2MB。一期（M0-M5 + 五轮修正 P1-P5 + 交互批）功能全部完成，224 vitest + 4 cargo 断言全绿。

## 快速上手

```powershell
# 前置：Node 20+/pnpm、Rust(MSVC)、VS BuildTools(C++)、WebView2（Win10/11 自带）
git clone https://github.com/L-iuhuan/MD-Read.git
cd MD-Read/modu
pnpm install          # npmmirror 已配
pnpm tauri dev        # 开发预览
pnpm run check        # tsc --strict + vitest 全量（224 断言）——提交前必须全绿
pnpm tauri build      # 产物 msi 在 src-tauri/target/release/bundle/msi/
```

家机（外网）环境搭建细节见 `docs/tasks/M0-环境搭建任务书.md` 家机段。公司机（内网）镜像配置已写入 `modu/AGENTS.md`（crates 清华源、npmmirror、PATH 陷阱）。

## 当前功能清单（全部已实现+验证）

- **阅读**：markdown-it 管线（GFM/脚注/emoji/锚点）、KaTeX（仅 `$$`/`\(`/`\[`，**禁裸 `$`** 金额红线）、中文伪公式降级、hljs 主题（亮暗）、Mermaid 懒加载、XSS 三防（html:false+DOMPurify+CSP）、相对路径图片、智能断行+justify 守卫（>400 块降级）、pangu 中西文插空（span 非破坏）
- **导航**：多标签（拖拽排序/懒挂载/fragment 缓存切换）、最近文件、大纲折叠+滚动跟随、Ctrl+F（双态路由）、行号、Ctrl+Tab 切换、Ctrl+W 关闭
- **编辑**：CM6 常驻单例、每标签状态存取、块级保位（Ctrl+E）、Ctrl+S + **自动保存（2s 防抖，开关默认开）**、BOM/CRLF 字节级保真（四例往返测试）、Ctrl+H 中文替换面板（右上角）
- **导出**：PrintToPdf 静默直出（A4/18mm/行级分页/鬼影防治/视外强制渲染/根链背景清零）；页眉仅日期+页脚仅页码（平台限制：无分离开关，print.rs 注释）
- **外观**：无边框+自定义标题栏（图标状态切换）、亮/暗/**自动跟随系统**三档、字号/行宽/字体族可调、代码块复制钮、沉浸淡出、FOUC 防闪、hljs/CM 面板/浮层统一设计语言（Radix 阶数纪律）
- **集成**：文件关联（.md/.markdown/.mdx）、单实例二次打开、外链交系统浏览器（nav-guard 兜底）、编码检测（UTF-8/GB18030）

## 测试与验收体系

- **单测**：`pnpm run check` = tsc --strict + vitest 224 断言（17 文件：render/tabs/editor/settings/theme/codecopy/links/images/wiring/css-fixes/…）；Rust `cargo test` 4 往返（BOM/CRLF/GB18030）
- **语料**：`modu/tests/corpus/` 7 份——语料.md（综合）、安全与伪公式.md（XSS/CJK 公式）、性能基线1MB.md（含 4000 公式）、性能无公式1MB.md（8700 块）、编辑测试.md（UTF-8 CRLF）、编辑测试GB.md（GB18030）、外链测试.md
- **活体验证**：dev 实例带 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9222` 启动 → agent-browser CDP 连入（eval/真实点击/截图）；坑见 AGENTS（会话目标漂移/超时）
- **性能基线**（2026-09-22）：1MB 无公式管线 459ms/墙钟约 2s（宪法红线 <1s 内容渲染达线，墙钟受挂载+IPC 制约）；1.8MB 含 4000 公式管线 1.9s
