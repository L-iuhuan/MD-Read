## 快速上手

```powershell
# 前置：Node 22+（CI 用 22 ✓）、pnpm 11+、Rust(MSVC)、VS BuildTools(C++)、WebView2（Win10/11 自带 ✓）
git clone https://github.com/L-iuhuan/MD-Read.git
cd MD-Read/modu
pnpm install          # npmmirror 已配
pnpm tauri dev        # 开发预览
# ⭐ 要开 CDP（9222）必须走 overlay：pnpm tauri dev --config ..\.verify\dev\tauri.dev-cdp.conf.json
#   ⚠ 设 WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS **没有用** ✗ —— Tauri 2 会覆盖它 ⇒ 端口不监听 ✓
pnpm run check:full   # tsc ×2 + eslint + vitest + vite build（**只跑 check 不压 CSS** ✗ 见 AGENTS）
# 提交**走脚本**（不是手动 git commit ✓）：node modu/tests/tools/commit-with-gates.mjs --msg <文件> -- <路径>
#   加 --full ⇒ 三道门禁：敏感 → check:full → cargo test ✓（改 src-tauri/** 必须带 --full ✓）
pnpm tauri build      # 产物 msi 在 src-tauri/target/release/bundle/msi/
```

家机（外网）环境搭建细节原载 `docs/tasks/M0-环境搭建任务书.md`（**刻意不入库**：早期过程任务书，不在 .gitignore 负向放行清单；需要时找原开发机）。公司机（内网）镜像配置已写入 `modu/AGENTS.md`（crates 清华源、npmmirror、PATH 陷阱）。
