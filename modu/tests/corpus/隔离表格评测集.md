# 隔离表格评测集（打印链路专用，2026-10-15）

> 用途：PDF 导出的表格渲染评测（fix-31 任务二，2026-10-15 扩充四档）。`tests/corpus/gfm-矩阵.md`
> 等已覆盖屏显表格形态，本集聚焦**打印链路**：markPrintBlocks 四档分类（T1 压列 / T2 缩放＋出血 /
> T3 横排压列 / T4 分栏切片）+ print.css 契约 + 渲染层 golden（列数 / 表头 / 单元格逐格文本）。
> 配套断言：`tests/table-print-eval.spec.ts` + `tests/table-slice.spec.ts`（切片器单元）。
>
> ⚠ 阈值说明：四档阈值 `830 / 1030 / 1400`（自 658/987 推导，见 print-ready.ts 注释）的
> **天然落点依赖真机字体度量**；jsdom 无真实布局，分类断言由 spec 对渲染产物**桩宽**（见该文件注释）。
> 本文件在真机上的预期：T1–T7、T9、T11 → T1 压列（T7 七列短 token 约 800 ≤ 830）；
> T10 十列 → T2 缩放＋出血；T13 十一列 → T3 横排压列（**判别表**：无切片的横排路径，
> 若真机 T13 也「一根线」则嫌疑转向横排命名页/261mm 规则本身，而非切片机制）；
> T8 十三列、T12 十六列 → T4 分栏切片。
