## 一、目标（有序列表 + 粗体 + 冒号，最容易被 tok-break 拆坏的形态）

1. **项目管理**：看板式管理全部项目的生命周期（想法 / 进行中 / 已上线 / 已搁置）
2. **知识积累**：蒸馏可复用资产（prompt、代码片段、组件、页面模板、检查清单）
3. **知识图谱**：项目、资产、笔记之间的关联可视化（力导向交互图谱，带防毛球策略）
4. **AI 原生**：AI 编程助手能直接读取、查询、维护这个库——这是核心差异化
5. **偏好记忆**：库中包含用户的编码 / 协作偏好，agent 读取后即了解用户习惯

**方向决策：工程花园骨架 + 博物馆皮肤（同一数据，两种皮肤）。**

展品级单栏排版、失败博物馆展厅、策展地图。维护成本高、AI 难参与——**现在不做**。

**第一性原则：一切视图都是派生的，人手只写内容。**

**v3 修正（审查结论）**：渲染层确实可随时替换，但**数据层**不能。
