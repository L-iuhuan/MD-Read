# 墨读（MoDu）宪法

> 固化裁决，分级：红线（违者合入无效）/ 强规（违者阻塞合入，修复后放行）/ 建议。修订须用户批准并记入规格 §9 台账。

## 红线

1. **安全三项不可拆**：CSP 显式配置、capabilities 按"渲染层已攻陷"设防、渲染管线 DOMPurify。`html:true` 永不开启。
2. **PDF 三禁**：禁 `@page` margin-box、禁光栅化导出、禁第三份打印样式（print.css 是唯一覆盖层）。
3. **编码不静默转换**：GB18030 文件保存保持原编码。
4. **数学分隔符**：禁裸 `$...$`（财务金额保护）。
5. **体积硬门禁 ≤8MB msi**：超限按预排顺序削减（hljs lib/common → KaTeX 字体子集 → emoji 短码 → Mermaid 最后），不许"先合了再说"。
6. **架构裁决 D1–D7 变更须评审**：任何一项翻案走多智能体评审 + 用户批准，禁顺手改。

## 强规

1. 质量门禁：`tsc --strict` + eslint + vitest 全绿才提交；渲染改动过 golden-HTML 对拍（含金额/引号/data-line 用例）。
2. 函数 ≤50 行、文件 ≤400 行；禁 `any`；禁宽/空 catch。
3. 里程碑制：每期验收标准（规格 §7）全绿才进下一期；收工交凭证三件套。
4. 主题色值只从 Radix 阶数取；结构刻度用 Open Props 最小集；亮暗双套同步验收。
5. 性能底线：1MB 文档内容渲染 <1s（冷启动单独计量）；禁 highlightAuto。
6. 双机纪律：push 前 `pull --rebase`；公司机镜像配置不回退官方源。

## 建议

1. 注释与文档中文；能用中文的文件名用中文。
2. 排版改动走截图验收轮（E2E 截图→修复→同名复核）。
3. 中文排版验收与浏览器默认渲染并排对照，不内部"通过"。
